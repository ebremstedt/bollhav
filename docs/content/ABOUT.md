# About

## Permissive by design

If you want, you can use the model objects as configuration, for whatever kinda of database you want to run against. But if you want, you can use the available implementations.

If you want, you can orchestrate your bollhav models using airflow, or you can use the built in orchestration that comes with the way bollhav stores state.

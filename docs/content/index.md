## What is bollhav?

A model definition framework for ingesting and transforming data.

Bollhav does not tell you *how to transform:* <br>
It gives you the scaffolding around the transform ✨**and then gets out of the way.**✨

## Explore the features

See [examples/](https://github.com/ebremstedt/bollhav/tree/main/examples) for self-contained, runnable pipelines that isolate each feature of bollhav.

## Installation

```bash
pip install bollhav
```
